# Java from Scratch

A chapter-wise organization of the practice programs from

## Table of Contents

### Chapter 1 — Numbers and Loops
Basic loop-driven number manipulation: no arrays, no classes, just `for`/`while` logic.

- `factorial.java` — factorial of a number
- `number_of_digits.java` — counting digits in a number
- `reverse_digits.java` — reversing the digits of a number
- `sum_of_digits.java` — summing the digits of a number

### Chapter 3 — Arrays Fundamentals
Core array operations: sums, indices, copies, sorting checks.
- `sum_of_all_elements_of_array.java` — sum of array elements

### Chapter 4 — Array Searching and Selection
Slightly more involved array problems: duplicates, extremes, occurrences.

### Chapter 5 — Array Sum Problems
